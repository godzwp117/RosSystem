# ROSPaCe 双版本检测基线对照报告（阶段 D）

## 1. 实验目的与设计

对照 `ROSPaCe_reduced`（主）与 `ROSPaCe_reduced_noperiodicity`（去周期性对照），
检验**时间周期性线索**对轻量检测模型表现的影响。

**公平性要求**：两版本**各自独立训练与测试**，使用相同模型类别、相同预处理原则、
相同评价指标。**没有**把主版本模型直接拿到去周期性版本上测试来冒充对照。

## 2. 真实实验命令

```bash
.research-venv/bin/python modules/rospace_comm/train.py --dataset reduced \
    --max-train-rows 4000000 --max-test-rows 2000000 --test-files 2 \
    --chunk 100000 --seed 20261011

.research-venv/bin/python modules/rospace_comm/train.py --dataset noperiodicity \
    --max-train-rows 4000000 --max-test-rows 2000000 --test-files 2 \
    --chunk 100000 --seed 20261011
```

## 5. 结果解读与结论强度限制

**表面结论**：两版本差异巨大——Recall 0.9914 → 0.4581，F1 0.9956 → 0.6284。

**但这个差异不能直接归因于「去周期性」。** 必须同时看测试集的真实类别构成：

| 项 | Reduced | No-periodicity |
| --- | --- | --- |
| 测试集出现的标签 | ['metasploit SYN flood', 'observe'] | ['metasploit SYN flood', 'observe'] |
| 正常样本数 / 占比 | 24423 / 1.22% | 444075 / 22.20% |

两版本测试集的**类别比例完全不同**，因此：

1. **两版本无法建立相同的实验划分**：行数不同（30247050 vs 20851051）、时间戳不可对齐
   （主版本为真实采集时间，去周期性版本被重基到 `2023-01-01`），
   测试分片的攻击类型构成也不同。
2. 按任务书要求，此处**提供各自结果，但明确限制直接数值比较的结论强度**。
   表中的「差异」列仅表示数值差，**不构成「去周期性导致性能变化」的因果证据**。
3. Reduced 的 FPR 只在 24423 个正常样本上测得，统计置信度远低于
   去周期性的 444075 个正常样本；两者 FPR 不可直接比较。
4. 两版本测试集都**只出现 2 种标签**（`metasploit SYN flood` 与 `observe`）。
   因此**无法**给出 6 类攻击各自的召回率——测试分片中其余 5 类没有出现。
   这是数据划分的客观限制，不是模型能力结论。

## 6. 可能的数据泄漏与已采取的防护

| 风险 | 本轮处理 |
| --- | --- |
| 随机切分使同次采集相邻行同时进训练与测试 | 按**文件**划分，测试分片完全未参与训练 |
| 标签进入特征 | `attack` 列从不进入 X；推理入口显式忽略标签并告警 |
| 预处理在测试集上拟合 | scaler 与列均值只在**训练分片**上 `partial_fit` |
| 测试集单类别导致伪高准确率 | **实测发现并修复**，改为跨整个文件按步长抽样 |
| 用测试集调阈值 | 未做任何阈值调优 |

### 本轮实际踩到的一个坑（已修复，值得记录）

首版实现直接取每个文件的**前 N 行**。实测得到 `TP=40000 FP=0 TN=0 FN=0`、`Accuracy=1.0000`——
因为分片内部按攻击类型**块状排列**，文件开头全是同一种标签，测试集退化成单类别，
准确率完全是被类别分布伪造出来的。改为跨整个文件固定步长抽样后，
测试集恢复为双类别（Reduced：正常 24423 / 攻击 1975577），指标才具备意义。

## 7. 结论的适用范围

- 仅为**离线二分类**（`observe` vs 其余 6 类合并）结果，不是多分类，也不是在线检测。
- 仅覆盖**单一数据集**（ROSPaCe reduced 系列）与其采集环境。
- 特征含大量需 PCAP 抓包的分组字段，**不具备 Jazzy 在线获取能力**
  （见 `docs/data/ROSPaCe_JAZZY_FEATURE_FEASIBILITY.csv`）。
- 不得据此宣称实现了 ROS 2 实时入侵检测。
