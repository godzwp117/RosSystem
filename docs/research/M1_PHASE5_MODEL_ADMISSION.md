## 3. 本轮的真实工程成果（与模型无关）

即使模型不能上线，以下能力是**已验证**并可交付的：

1. **时间驱动窗口**：零业务消息也能闭合窗口并输出图特征（G1）；
2. **双通道分离**：消息不足不再污染图观测的有效性判定（G1）；
3. **graph-only 攻击可观测**：churn 与 graph-only churn 实测 45/46 次变化，
   稳定场景仅 2–3 次（G2）；
4. **明确的能力边界**：纯查询侦察在快照上不可观测（2 次 ≈ 稳定），
   极短命端点漏采（0 次）—— 两条都是可复现的实测结论（G2）；
5. **可复现数据集**：30 个独立会话、双通道、标签可信、失败记录保留（G3）。
