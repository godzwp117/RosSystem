## 1. 相对 v1 的方法学修正

| v1 | v2 |
| --- | --- |
| "最差会话 F1"（含正常会话） | 正常用 `worst_session_fpr`，异常用每类 `recall` |
| 单一 F1 门槛 | 三类门槛分开：总体 FPR、最差会话 FPR、每类召回 |
| 未定义单类会话 | 无正类 → recall/F1 = N/A；无负类 → FPR = N/A |
| 无覆盖质量 | 图覆盖率 < 50% 的窗口降为 DEGRADED 并计入覆盖统计 |
| 无盲测隔离 | 训练/验证/盲测按**批次**隔离，盲测只在模型与阈值冻结后跑一次 |

## 2. 数据批次划分（本轮实际执行）

| 批次 | 内容 | 会话数 | 用途 |
| --- | --- | --- | --- |
| 训练/验证池 | 第五轮 g3 + 第六轮补采 | 正常 27，异常 15 | 留一会话评估、通道消融 |
| **盲测批次** | `p6-blind-*`（不同速率、重启、短命端点、三类异常） | 计划 24 | **仅在模型冻结后运行一次** |

盲测批次的设计要点：

* 正常侧包含**短命端点**（`p6-blind-norm-blip-b0`）—— 图上有变化但合法；
* 正常侧速率与训练批次不重叠（4/25/60/120/250/600 Hz vs 3/7/15/30/75/150/300/750）；
* 三类异常各 5 个，独立采集；
* **盲测结果在看到之前不参与任何选择**。

## 3. 预登记门槛（v2）

| 项 | 门槛 | 适用 |
| --- | --- | --- |
| `overall_fpr_pooled` | ≤ 0.10 | 正常会话汇总 |
| `worst_session_fpr` | ≤ 0.50 | 任一正常会话不得全线误报 |
| 每类异常召回 | ≥ 0.80 | 至少 5 个会话中检出 4 个 |
| 图覆盖率 | ≥ 0.50 | 低于此的窗口不进入评估 |
| UNKNOWN 占比 | ≤ 0.20 | 正式模型阶段才可测 |

**任一不达标 → 不导出正式模型。**
