## 5. 你负责的真实数据来源

### 主数据集：ROSPaCe reduced

| 项 | 值 |
| --- | --- |
| 官方合集 | https://springernature.figshare.com/collections/ROSpace_Intrusion_Detection_Dataset_for_a_ROS2-Based_Cyber-Physical_System/6924364 |
| 本地路径 | `data/ROSPaCe_reduced/` |
| 主数据集 | `ROSPaCe_reduced`，15 个分片，约 **3,024.7 万条** |
| 对照数据集 | `ROSPaCe_reduced_noperiodicity`，10 个分片，约 **2,085.1 万条** |
| 特征依据 | `feature_list.xlsx`（482 条特征） |
| 每条记录 | 62 列（含标签 `attack` 与时间戳） |

**实测标签**（7 类，字符串，不是 0/1）：

| 标签 | 含义 | 主数据集占比 |
| --- | --- | ---: |
| `observe` | **正常** | 21.97% |
| `metasploit SYN flood` | 攻击 | 48.59% |
| `nmap SYN flood` | 攻击 | 26.43% |
| `nmap discovery` | 攻击 | 1.65% |
| `ros2 reconnaissance` | 攻击 | 1.33% |
| `ros2 node crashing` | 攻击 | 0.019% |
| `ros2 reflection` | 攻击 | 0.012% |

**二分类映射**：`observe`=0（正常），其余 6 类=1（攻击）。

### ⚠️ 必须知道的研究现状（负面结论）

现有研究代码在**独立研究分支** `feature/rospace-dataset-adapter` 的
`modules/rospace_comm/`。当前状态**不适合直接交付**：

| 事实 | 数值/说明 |
| --- | --- |
| 实验使用的模型输入特征 | **49 个**（从 `feature_config.json` 实测） |
| 原始非标签字段 | **61 个** —— **不得与模型输入数混用** |
| 直接在线可获取的模型特征 | **仅 2 个**（`publishers_count`、`subscribers_count`） |
| 当前模型 F1 | 0.1967 |
| 当前模型 Recall | 0.1091（**严重漏报**） |
| "恒预测攻击"简单基线 F1 | **0.8235** —— **模型劣于无脑基线** |
| 数据划分 | `FILE_DISJOINT_SPLIT`，**不足以证明跨会话泛化** |
| 在线监测 | `RUNTIME_MONITOR: NOT_READY` |

**旧版高 F1（0.9956）不可用**：该版本有两个真实缺陷
（流式预处理统计量不固定、分片字符串排序），结果已被证伪。

**漏报主因不是阈值**：实测 75% 样本（含大量攻击样本）的攻击概率低于 `1e-5`；
阈值降到 0.001 时 Recall 仅从 0.070 升到 0.095。**是模型没学到判别边界。**

### 一定要避免的坑

1. **分片内部按攻击类型块状排列** —— 取文件前 N 行会得到单类别测试集，
   会伪造出 `Accuracy=1.0`。
2. **每个数据集只有 `_0` 分片带表头**，其余分片首行即数据。
3. **不要用测试集调阈值**；不要在**同一连续攻击区块**内随机拆分训练/测试。
4. **不要用标签作弊**（把标签当特征、按标签造预测值）。

## 7. 模块输入与输出契约

**输入**：stdin 一个 `ModuleInputEnvelope`（JSON）
**输出**：stdout 一个 `CommRiskEvidence`（JSON）
**诊断日志**：**stderr**（stdout 只能有一个 JSON 对象）

**关键状态语义**：

| 状态 | 含义 |
| --- | --- |
| `NORMAL` | 允许推进 |
| `SUSPICIOUS` | **阻断** |
| `UNKNOWN` | **阻断**（不等于正常） |
| `ERROR` | **阻断**（模块自身失败） |

**重要约束**：

- `anomaly_category` 只能用既有枚举：
  `NONE` / `REQUEST_RATE_ANOMALY` / `DUPLICATE_CALL_PATTERN` /
  `TIMING_DEVIATION` / `UNEXPECTED_RESOURCE_ACCESS` / `NODE_RELATION_ANOMALY` / `UNKNOWN`。
  **不要新增枚举值**（旧实现用 `NETWORK_TRAFFIC_ANOMALY`，导致攻击预测被 Schema 拒绝）。
- `producer.source` 只能是 `MOCK` / `EXTERNAL` / `UNKNOWN`。
- `evidence_refs[].kind` 只能是 `MOCK` / `RUNTIME_LOG` / `PERMISSION_FILE_ANALYSIS` /
  `CONTROLLED_SECURITY_EXPERIMENT` / `UNIT_TEST` / `UNKNOWN`。
- **不要修改 Schema 来迁就你的输出。**

## 9. 实验与评价指标

**必须报告**（不能只报 F1）：

- F1、Balanced Accuracy、Precision、Recall、FPR
- **正常样本识别能力**（specificity）
- 测试集类别占比
- 各**实际可评测**攻击类别的 Recall（未出现的类别标 `NOT_EVALUATED`）
- 与**恒预测攻击**和**恒预测正常**两个简单基线的差异
- PR-AUC（能算则给，不能算说明原因）

**严格区分三个指标**：

- **二分类 Macro Recall** = `(Recall_attack + Recall_normal) / 2`，
  其中 `Recall_normal = TN/(TN+FP)`；二分类下**等于** Balanced Accuracy。
- **`macro_attack_detection_recall`** = 各攻击类别检测召回的平均（另一个指标）。
- 正常类的"被判为攻击比例"是**误报率**，**不是**召回率。

## 11. 必须完成的测试

**单元测试**

- 标签不得进入特征（构造含 `attack` 列的输入，断言被忽略或报错）
- 预处理参数只在训练集拟合（测试集不参与）
- 指标定义正确（**用手工混淆矩阵验算**，不要用同一函数两次生成的结果互相比较）
- 缺模型 / 模型损坏 → 必须安全失败，**不得默认返回正常**
- 缺特征 / 特征顺序错误 → 必须安全失败，**不得静默填 0**

**集成测试**

- 正常样本 → `NORMAL` → 适配层 `READY_FOR_GATEWAY_SUBMISSION`
- 异常样本 → `SUSPICIOUS` → 适配层 `ADAPTER_BLOCK`
  （阻断原因必须是**模块状态不允许推进**，不是 Schema 无效）
- `UNKNOWN` / `ERROR` → 必须阻断
- 真实攻击预测**必须由模型实际产生**，不得构造非法 Schema 冒充检测成功
